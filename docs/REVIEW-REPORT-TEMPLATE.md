## Scope and findings

For each check, identify the protocol requirement, expected result, observed result, evidence path and status (agrees / discrepancy / not assessed). Include minimal reproducible counterexamples. Distinguish independently derived conclusions from author-supplied checks.

## Coverage and limits

List tested roots/cells, omitted checks, modeling assumptions and unresolved questions. Arithmetic agreement alone does not establish semantic correctness; exact replay is not fresh-root replication.

## Discrepancies and recommended disposition

For each discrepancy: scientific consequence, affected versions/results, proposed correction, and whether new outcomes would need a new prospective commitment. Do not discard failed conditions.

## Maintainer response (separate from reviewer findings)

Record accepted/rejected findings with reasons, correction commits, rerun scope, changed claims and outstanding issues. Leave the reviewer's original report intact.
