# GVA-0 post-publication review response — v0.5.1

The review was supplied by the project maintainer as Claude-generated feedback after the first public release. It is not journal peer review or independent replication. We retain v0.5.0, the exact original scientific protocol, core, results and hashes. This revision changes interpretation/presentation and adds explicitly post hoc analyses on archived roots. The original D_B/D_R definitions and .05/.20 margins are unchanged.

| Concern | Assessment and implemented response |
|---|---|
| Predictable constructed result | Accepted. The title, abstract and Discussion now describe verification of a deliberately engineered mechanism. The t intervals quantify variation within the construction; they do not measure surprise, novelty or external validity. |
| R is not specific to harmful proxy exploitation | Accepted. The paper gives the channel2 counterexample and emphasizes harm plus reporting interventions. The channel-by-search difference-in-differences is reported as exploratory. We do not retroactively promote it to the frozen primary family or remove R from the historical conjunction. GVA-1 has no R efficacy criterion. |
| Shift is not independent replication | Accepted. Both primary D_R root vectors coincide, exhaustive actions are identical, and primary faithful/nominal preview outcomes coincide. The shift is described as harsher consequences along the same primary path. Channel2's shifted R48=.154167 uses faithful previews; the matched nominal-preview value is .204167. The qualitative R criticism holds in either case, but modes are kept separate. |
| Displacement not identified | Accepted. Retitled around harm on an admissible path. Main Results now state nominal unrestricted/enforced K48 B=.466146/.118229. New post hoc unrestricted K4 B=.317708 versus zero enforced supplies the missing comparison. It does not prove causal movement from an illegal path or reverse enforcement's observed harm reduction. |
| K4 mostly noop; two-budget limitation | Accepted. Ran K=1,2,4,8,16,32,48 for two channels, both enforcement settings and both physical regimes: 1,120 episodes. Report all activity frequencies. Nominal enforced channel0 B peaks at K32=.135938 then falls at K48=.118229. We explicitly reject a monotonicity claim. |
| Bonferroni versus intersection-union | Partly accepted. An all-pass conjunction needs no Bonferroni correction for a level-.05 intersection-union test, regardless of dependence. But the published Bonferroni simultaneous bounds are valid, not inaccurately named. The original stronger coverage requirement is preserved. The illustrative unadjusted nominal lower bound is .106305 using t19,.95=1.729133, versus the frozen .101448. Four criteria contain only three distinct observed difference vectors. |
| Supported production, horizon and threshold dependence | Accepted. Corrected the Discussion to the selected q1/u1 action: first-step zero drift, subsequent −20 nominal and −40 late shifted, before noise. Added a complete 54-cell fixed-policy sensitivity factorial over horizons, thresholds and group-B start intervals. This is a policy sensitivity, not a claim about optimized behavior beyond the original setting. |
| Development-only witnesses | Added a labeled exploratory check on all 480 primary K48 live states. Bias-on replay matched every original action; 960 on/off score banks matched scalar calculations. Strict witnesses occur in 89/240 nominal and 84/240 shifted contexts, covering 20 roots each. All unsuccessful contexts are included. These are not fresh confirmatory observations. |
| Process leakage and authorship | Removed “the user's authorization” from the manuscript. Added a task-specific ChatGPT/Codex contribution disclosure and the origin of this critique. HumanAI Convention is identified as maintainer. Personal PI name and affiliation remain pending rather than being invented. |
| Off-topic fusion and unclear V/seeds | Moved the full fusion methods block to Supplement S0, retained every original secondary table, defined V, and explained 61 named streams per root shared across cells (1+12×5=61; 20×61=1,220). |
| Related work | Added primary-source citations to Pan/Bhatia/Steinhardt, Skalse and colleagues, Manheim/Garrabrant, and Krakovna and colleagues' specification-gaming article/catalogue. |
