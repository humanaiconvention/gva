## S6. Freeze and reproduction

Use the published exact execution-core files and pinned runtime with the portable reproduction runner. The wrapper is an author-provided publication adaptation; its complete 820-episode outcomes are checked against the archived results. This is reproduction, not an independent confirmation. Existing output directories are never overwritten.

```sh
python scripts/verify_release.py
python reference/reproduce.py --output reproduction
```

[Execution addendum](../docs/PROVENANCE.md) records authorization, namespace wiring, preselected audit roots and the no-interim-look procedure. [Freeze manifest](../provenance/FREEZE.original.json) commits the unchanged preregistration, code archives, seed manifest and runtime. Hash checking is tamper-evident under trusted local storage; no external registration is asserted.
